A real agent, not a chat window

Everything below ships inside lite and full. Zero third-party crates: TLS, HTTP, JSON and the interpreter are written from scratch.

Subagents

The model hands a large search or side task to the task tool: a fresh conversation with its own tool loop that reports back a summary, so the main context stays small.

> find every unit that restarts in a loop
  and tell me why

⏺ task: check systemd units for restart loops

Skills

Drop a SKILL.md into .emerag/skills/. Only the name and description go into the prompt; the body loads when the model needs it.

---
name: nginx-repair
description: diagnose nginx startup failures
---
1. nginx -t
2. ss -ltnp | grep :80

MCP servers

Any stdio MCP server becomes a set of tools named mcp__server__tool. Even a shell script that speaks JSON-RPC works.

{"mcpServers": {
  "fs": {"command": "mcp-server-filesystem",
         "args": ["/srv"]}
}}

Integrated script engine

A Lua 5.4 subset with file, JSON, hash and raw syscall functions. It keeps working when there is no shell, or when the PID limit stops anything from forking.

for _, e in ipairs(fs.list('/var/log')) do
  if e.size > 1e9 then print(e.name, e.size) end
end
print('pids', sys.pid_limit().soft)

Also included: shell, read/write/edit, grep and glob tools; per-call approvals; background jobs; multiple sessions with /new, /fork and  & background turns; DeepSeek, OpenAI, Anthropic, OpenCode and local models.

Built for the bad day

Read-only root?

The installer runs from /dev/shm or a memfd. Nothing is written to disk.

DNS broken?

Built-in resolver, --dns and --resolve. Nano has --ip.

Out of PIDs?

No daemon, no helpers. The script engine works without forking.

Serial console?

ASCII and cooked modes, 40 columns, no arrow keys needed.

Tiny router?

Lite is 549 KB on ARM. Nano is 44 KB.

Air-gapped?

Point it at ollama, llama.cpp or LM Studio, or run emerag local up.

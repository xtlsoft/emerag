// inside

Everything an agent needs. Nothing it doesn't.

TLS, HTTP, JSON, crypto and a Lua interpreter, written from scratch. Zero third-party crates.

Subagents

Big searches run in a fresh context and report back. The main thread stays small.

> find why nginx dies after boot
⏺ task: trace nginx failures in the journal

Skills

Markdown playbooks, loaded only when the model needs them.

# .emerag/skills/nginx/SKILL.md
name: nginx-repair
description: fix nginx startup failures

MCP

Any stdio MCP server becomes tools. A shell script works.

{"mcpServers": {"fs": {
  "command": "mcp-server-filesystem"}}}

Script engine

Lua 5.4 with file and syscall access. Works with no shell and no free PIDs.

for _, e in ipairs(fs.list('/var/log')) do
  if e.size > 1e9 then print(e.name) end
end

Plus shell, file and search tools, approvals, background jobs, parallel sessions, and DeepSeek, OpenAI, Anthropic or local models.

Built for the bad day

Everything a normal agent assumes, emerag doesn't.

Node, glibc, working DNS, a writable disk and a modern terminal fail exactly when you need help most. emerag only needs a kernel that can exec a file.

/ ro

Read-only root

The installer runs straight from /dev/shm or a memfd. Nothing touches the disk you are trying to save.

NXDOMAIN

DNS is lying

Built-in resolver, --dns, and curl-style --resolve. Certificates still verify against the real hostname.

EAGAIN

No processes left

When fork fails, the built-in Lua engine still reads, writes, stats, chmods and kills, with zero child processes.

9600 8N1

Serial console

VT100, 40 columns, no Unicode, no colour, no arrow keys. ASCII and cooked modes are first-class.

i586 · s390x

Odd hardware

Static builds for x86, ARM, RISC-V and s390x, plus a C89 client that runs on Windows 98, NT4 and XP.

air-gap

No internet at all

Point it at ollama, llama.cpp or LM Studio, or use emerag local up from the self-contained offline bundle.

Under the hood

A full agent, written from scratch.

TLS 1.2/1.3, HTTP, JSON, X.509, crypto and a Lua 5.4 interpreter are all hand-written in plain Rust and std. That is why it builds offline and cross-compiles anywhere.

tools

Real tools, real approvals

Shell (bash, zsh, fish, cmd, PowerShell), read/write/edit, grep, glob, background jobs and sudo, with per-call approval and four permission modes.

providers

Any model you have

DeepSeek (API key or account sign-in), OpenAI Chat and Responses, Anthropic, OpenCode and any compatible endpoint. Reasoning streams live.

sessions

Many conversations

/new, /fork, /session, plus background turns with  & you can /wait on or /kill.

mcp

MCP and skills

Stdio MCP servers become namespaced tools. SKILL.md folders load on demand, and subagents take on side quests.

doctor

Knows where it is

Every session probes the OS, shells, DNS, writability and memory, so the model starts with the facts. --doctor prints them for you.

private

No telemetry

No update check and no analytics. It talks to the endpoint you configure and nothing else.

Three sizes

Pick the smallest one that does the job.

Same mission, three trade-offs. Full is the reference build with verified TLS. Lite drops the CA bundle to fit on tiny routers. Nano is a C client for machines Rust can't reach.

nano

44 – 83 KB

For Windows 98, XP and the smallest Linux boxes.

  • C89, builds with Visual C++ 6.0
  • TLS 1.3, HTTP/1.1, Chat Completions
  • shell loop, /compact /model /yolo
  • no tools JSON, MCP or sessions
  • no certificate verification

lite

530 – 630 KB

The whole agent, sized for OpenWrt routers.

  • every tool and the Lua engine
  • sessions, MCP, skills, subagents
  • OAuth sign-in, provider catalog
  • static musl, UPX-packed
  • no CA bundle, no certificate checks
RECOMMENDED

full

1.3 – 2.0 MB

The reference build for rescue media and servers.

  • everything in lite
  • embedded 118-root Mozilla CA bundle
  • verified TLS 1.2/1.3, SPKI pinning
  • x86, ARM, RISC-V, s390x, Windows, macOS
  • zero shared libraries on Linux

Verify what you run

The installer checks SHA-256 automatically, using curl, wget or busybox wget. To check a manual download:

sha256sum -c SHA256SUMS --ignore-missing

Installer options
